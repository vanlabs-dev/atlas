# Acceptance checklist

- [x] Verify repository write credential with temporary remote branch and readback.
- [x] Create isolated development checkout and test environment.
- [x] Establish existing subsystem baseline inside network/credential isolation.
- [x] Persist contiguous finalized runtime detection and replay tests.
- [x] Validate deployed runtime artifact/source mapping and complete evidence.
- [ ] Exercise pinned, tool-free unattended inference and independent review.
- [ ] Verify candidate policy, isolated suites and exact-tree receipts.
- [ ] Verify deterministic publication and remote readback.
- [ ] Verify quiescent local rollout, knowledge activation and rollback.
- [ ] Integrate durable maintenance notifications and user timers.
- [ ] Obtain the one-time system-timer migration privilege step.
- [ ] Complete a real pending upgrade, publish and activate it.
- [ ] Verify unchanged polling, restart recovery and final acceptance report.

Only mark items when real execution provides the receipt. Publication of the
implementation is not proof that the pending network upgrade is fully audited.
